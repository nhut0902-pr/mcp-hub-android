Hướng dẫn cài đặt APK
  1. Tải file .apk về điện thoại Android.
  2. Mở file (qua ứng dụng Files hoặc thông báo tải xuống).
  3. Cho phép "Cài đặt từ nguồn không xác định" khi Chrome/Files yêu cầu.
  4. Mở app MCP Hub và nhấn Đăng nhập qua NhutCoder Team.
  5. Trình duyệt mở trang /mobile-login trên nhutcoder-team-v2.vercel.app.
  6. Đăng nhập bằng tài khoản NhutCoder Team (cùng tài khoản với web).
  7. Sau khi đăng nhập, app tự quay lại và bạn có thể dùng Nhutbot 1.0 Flash.

Yêu cầu: Android 7.0 (API 24) trở lên · Kết nối Internet · Tài khoản NhutCoder Team
